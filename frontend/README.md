# Nurfia Fashion - Frontend

This is the React-based frontend for the Nurfia Fashion eCommerce platform.

## 🚀 Key Components
- **Product Gallery**: Interactive image preview with thumbnail support.
- **Cart & Wishlist**: Persistent state management for shopping convenience.
- **Admin Layout**: Integrated dashboard for site management.
- **Responsive Navigation**: Adaptive header and footer components.

## 🛠 Setup
1. Install dependencies from the repository root (use the root `package-lock.json`):
   ```bash
   npm install
   ```
2. Run the development server from the repository root:
   ```bash
   npm run dev:frontend
   ```

## 📦 Build
To create a production build from the repository root:
```bash
npm run build --workspace frontend
```

The output will be available in the `frontend/dist` directory.
